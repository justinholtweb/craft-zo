# Plugin Store promo images

Marketing images for the Zo listing on the Craft Plugin Store, rendered in the same theme as the
plugin's marketing page at
[justinholt.com/plugins/craft-zo](https://justinholt.com/plugins/craft-zo).

## Building

```bash
./build.sh          # all slides
./build.sh "2 5"    # just slides 2 and 5
```

Output lands in `out/` as `zo-promo-N.png`, 1920×1080 (rendered at 2× in headless Chrome, then
downsampled so the type stays crisp).

Every slide is pure CSS and type — there are no control-panel screenshots yet. When the CP settles,
screenshot slides can be added alongside these without redoing anything: copy the `.shot` /
`.viewport` pattern from `craft-appleseed-website/promos/slides.html`.

## Editing

Everything lives in `slides.html` — one `<section class="slide">` per image. The palette and fonts
are the plugin site's: accent `#1F5F8B`, Jersey 20 for display, Inter for body.

`assets/` holds the fonts and two icon files:

- `icon.svg` — the Plugin Store tile, a byte copy of `../src/icon.svg`: the accent rounded square
  with the ledger mark in solid white, and the spine, the Z and the ruled line knocked out of it
  with `fill-rule="evenodd"`. `../src/icon-mask.svg` is that same path alone, for the contexts
  Craft renders as a mask.
- `watermark.svg` — ruled ledger lines with the icon's own Z laid over them. The page outline is
  deliberately absent: at ~1120px on a slide the icon's border is a hard-edged box, and a box is
  not a mark. Fine rules read as paper at any size.

`fonts.css` is generated by `build.sh` (the woff2 files are base64-inlined so Chrome's `file://`
origin rules can't block them) and is not checked in.
